# ✨ Features

## Customer Portal

- Customer Registration & Login
- Online Booking
- Ticket Booking
- Outbound Booking
- Cafe Reservation
- Payment
- QR Ticket
- Download PNG
- Download PDF
- Booking History
- Customer Profile
- Notifications
- Responsive Mobile UI

## Admin

- Dashboard
- Master Data
- Booking Management
- Customer Management
- Reports

## Backend

- REST API
- Worker Service
- Prisma ORM
- Modular Architecture
