# Model Domain SATSET ERP

Domain utama dan hubungan bisnis:

- Ticketing
  - Objek utama: tiket, kode akses, tipe tiket.
  - Tanggung jawab: penerbitan, validasi, pembatalan.

- Reservation
  - Objek utama: reservasi, hold aset, jadwal kunjungan.
  - Tanggung jawab: alokasi slot, manajemen kapasitas.

- Gate
  - Objek utama: scanner event, status entry, akses valid.
  - Tanggung jawab: verifikasi tiket dan tracking akses.

- Inventory
  - Objek utama: stok barang, inventori cafe, souvenir.
  - Tanggung jawab: pengurangan stok, restock, status ketersediaan.

- Finance & Accounting
  - Objek utama: transaksi, invoice, settlement.
  - Tanggung jawab: pencatatan pendapatan, laporan keuangan dasar.

- CRM
  - Objek utama: pelanggan, interaksi, histori pelanggan.
  - Tanggung jawab: personalisasi layanan dan retensi.
