# Arsitektur AI SATSET ERP

AI dalam SATSET ERP berfungsi sebagai pendukung keputusan dan automasi bisnis.

Kemungkinan use case:

- Prediksi permintaan tiket dan occupy rate.
- Rekomendasi penawaran promosi atau paket pelanggan.
- Analitik pola antrian dan optimalisasi gate.
- Otomasi layanan pelanggan dasar untuk FAQ dan notifikasi.

Prinsip integrasi:

- AI diposisikan sebagai layanan bantu, bukan sumber kebenaran utama.
- Model mengonsumsi data historis dari domain operasional.
- Hasil AI dipakai untuk insight, rekomendasi, dan peringatan.
- Keamanan data dan privasi tetap dijaga saat memproses data pelanggan.
