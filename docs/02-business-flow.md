# Alur Bisnis SATSET ERP

Alur bisnis inti mencakup empat pilar operasi:

1. Penjualan dan reservasi
   - Pelanggan membeli tiket atau memesan layanan melalui kanal digital.
   - Sistem memvalidasi ketersediaan kapasitas dan mencatat data transaksi.

2. Akses dan gate operations
   - Tiket diverifikasi di pintu masuk menggunakan scanner.
   - Status akses dicatat untuk audit dan analitik.

3. Operasional layanan lamun
   - Cafe dan souvenir mengelola stok serta penjualan secara real-time.
   - Integrasi dengan inventori memastikan ketersediaan produk.

4. Keuangan dan pelaporan
   - Semua transaksi dikonsolidasikan untuk rekonsiliasi dan laporan keuangan.
   - Data digunakan untuk analitik pendapatan dan KPI operasional.

Flow ideal:
- Pelanggan reservasi/tiket → sistem ticketing/reservation → validasi gate → layanan on-site → pencatatan keuangan.
