# Peta Modul SATSET ERP

Peta modul mencerminkan batas domain dan tanggung jawab:

- `ticketing`
  - Penjualan tiket
  - Penerbitan dan validasi tiket

- `reservation`
  - Manajemen reservasi
  - Alokasi kapasitas dan penjadwalan

- `gate`
  - Kontrol akses
  - Integrasi scanner dan event entry

- `inventory`
  - Manajemen stok cafe dan souvenir
  - Aliran barang dan penjualan on-site

- `cafe`
  - Order dan pembayaran layanan makanan/minuman
  - Integrasi ke inventory dan finance

- `souvenir`
  - Manajemen produk cenderamata
  - Transaksi di toko souvenir

- `finance` / `accounting`
  - Rekonsiliasi transaksi
  - Dasar pembukuan dan pelaporan pendapatan

- `crm`
  - Data pelanggan
  - Interaksi dan loyalty

- `ui`
  - Komponen antar muka bersama
  - Tidak membuat UI konkrit di blueprint ini

- `shared`
  - Kontrak, utilitas, dan model umum

- `database`
  - Konsep data dan pengelolaan skema
