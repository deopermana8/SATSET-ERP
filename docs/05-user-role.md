# Peran Pengguna SATSET ERP

Peran utama dalam ekosistem:

- Admin Bisnis
  - Mengelola konfigurasi layanan, harga tiket, dan dashboard kinerja.
  - Akses penuh atas laporan dan data operasional.

- Operator Gate
  - Mengoperasikan scanner dan memantau antrian masuk.
  - Bertanggung jawab atas validasi akses dan eskalasi jika ada kegagalan.

- Kasir Cafe/Souvenir
  - Menjual produk dan mencatat transaksi on-site.
  - Mengelola stok real-time untuk item konsumen.

- Staff Reservasi
  - Memproses permintaan reservasi dan menyesuaikan kapasitas.
  - Menghubungi pelanggan untuk konfirmasi dan perubahan jadwal.

- Pelanggan
  - Memesan tiket/reservasi dan menerima konfirmasi.
  - Menggunakan tiket saat kunjungan.
