# Glosarium SATSET ERP

Istilah bisnis utama:

- Tiket: bukti akses yang dikeluarkan untuk pelanggan.
- Reservasi: pemesanan slot kapasitas atau layanan.
- Gate: titik masuk di mana akses diverifikasi.
- Inventory: stok barang dan produk yang dijual di lokasi.
- Transaksi: catatan keuangan atas penjualan dan pembayaran.
- CRM: manajemen hubungan pelanggan.
- Modul: unit fungsional dalam platform.
- Kontrak: definisi data dan API antar domain.
